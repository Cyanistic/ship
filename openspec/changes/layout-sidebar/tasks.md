# Tasks

Checkpoints for implementing the locked plan, one slice at a time.

The papers were locked on 2026-10-10. The planning gates G1 to G7 are settled (`design.md`, Settled gates) and folded into the tasks below. Complete and verify one vertical slice, then stop before the next.

Verification uses real workflows and temporary probes, not permanent authored tests. For each implemented checkpoint run applicable `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, debug/release builds, and ship-core checks with and without `clap`; record any unavailable command honestly. Use owned temporary servers/probes, do not restart existing user work, and clean up only resources created for the exercise. Rendered terminal checks are required where appearance is part of the result. Linux/macOS checks count only when actually run on that local platform; Windows remains unverified.
