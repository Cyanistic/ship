# Tasks

Checkboxes record completed implementation checkpoints. Writing this file does not authorize source changes. Follow the locked papers indexed by design.md; the program paper's skeleton map and build order are authoritative for files and interfaces, and its architecture amendments A1 to A6 override the original architecture decisions they name. Under an implementation request, finish and verify one slice, record actual evidence and any surprise in the program paper's Deviation log, then stop; do not begin the next slice in the same run. A surprise that contradicts a locked paper reopens it under the design-rules ripple rule before work continues. Unavailable exercises stay explicitly unverified.

Every slice runs workflows against a foreground `ship server --port <p>` with `--server-url http://127.0.0.1:<p>` on each client, ends with `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings` and debug and release builds passing, and adds no permanent tests. Slices that touch routes or protocol types rerun the disposable `openapi()` consumer outside the repo. Every slice runs on macOS; slices 2, 5 and 7 also run on Linux or are recorded as unverified there.
